# 小众性癖

> romance-master 体系的一部分。还没加载 `romance-master` 和 `method` 的话，先加载它们——这一份只装知识，档案、规矩和说话的方式在那两份里。

先说态度：**性癖本身没有道德问题。** 想绑人、想被打、想被叫某个称呼、想玩角色——这些是成年人性生活的正常光谱，不是病，不需要被"理解"或被"接纳"。

这份 skill 存在的理由是另一件事：**这类玩法里有几样是真的会造成永久伤害的**，而伤害几乎总是来自"没谈"和"不知道"，不是来自"玩得重"。所以下面是关于怎么谈、以及风险到底在哪。

## 协商：先谈，再玩

这不是流程上的客套。**没谈过的玩法，不做。**

**谈什么：**

- **限界**。分两档，必须分开问：
  - **硬限** —— 绝对不做的事。不问就不算数。
  - **软限** —— 不太想，但某种情况下可以试试。软限**不能**当成"其实可以"。
- **具体到动作，不要用类别词。** "我想试试 BDSM"什么都没说。"我想被绑住手腕、蒙眼、然后被扇巴掌"才是可以同意的。
- **安全词**。约定一个**在场景里不会被正常说出来的词**——"不要"和"停"在这种场景里天然不可靠，因为它们可能正是台词的一部分。
  - 红黄绿系统：绿=继续，黄=缓一缓/轻一点，红=立刻停。
  - 说不出话的时候（堵嘴、窒息）需要一个**非语言信号**：手里握个东西，掉了就是停；或者捏两下。
- **什么时候结束**，以及结束后发生什么。
- **身体限制病史**：颈椎、腰、关节、心脏、哮喘、凝血、正在吃的药。这些不是"扫兴的问卷"，是决定哪些玩法根本不能做的信息。
- **这次不做的事**也说出来。"今天不想做任何疼的"是一个完整的、无需理由的声明。

**谈到什么程度：** 谈到双方都能把要做的事复述一遍的程度。**"我以为你懂"是这类事故的头号原因。**

**随时可以撤回。** 同意了不代表这次必须做完。中途改主意不需要理由，也不需要道歉。

## 风险框架

圈子里有三个说法，意思相近但侧重不同：

- **SSC**（安全、理智、自愿）：最老的框架。
- **RACK**（风险自知共识）：承认很多玩法**本来就不安全**，能做的是知情和自愿承担风险。比较诚实。
- **PRICK**（个人责任、知情共识）：强调自己为自己负责。

**这套东西里用 RACK。** 因为下面有几样确实是高风险的，说"安全"是骗人。正确的做法是把风险讲清楚，让用户自己判断。

## 各类玩法，以及风险在哪

### 束缚 / 捆绑

**真正的风险是神经和循环，不是"绑得紧不紧"。**

- **手腕**：桡神经浅支被压 → 手背麻、拇指无力（"wrist drop"）。**麻和刺痛是立刻松绑的信号，不是"忍一下"**。
- **脚踝**：腓神经 → 足下垂。同理。
- **上臂**：桡神经绕肱骨走，绑太紧会伤。
- **腋下/肩**：臂丛神经，很容易伤。
- **绝对不要绑脖子，也不要任何形式的悬吊。** 悬吊需要专门的训练和装备，业余做就是脊髓损伤。
- **永远不要让被绑的人独自待着。** 一秒钟都不行。这是没有例外的规矩。
- **手边必须有安全剪**（急救剪，圆头那种），不是普通剪刀，不是指甲刀。随时能用。
- **检查频率**：每 10-15 分钟看一次颜色、温度、感觉。发紫、发凉、麻木 → 松。
- **绑的姿势不要让人无法呼吸或无法吞咽**，尤其是趴着和吊臂的姿势。
- **松绑后**：血液回流会疼，是正常的。麻和无力超过几分钟不正常。
- 用**专门的束缚带/绳**，不要用领带、电线、绳子细且会打结的。宽一点的分散压力。

**具体怎么绑：**

**从哪开始：手腕，绑在身前。** 不要第一次就背后绑手——背后需要对方完全信任，而且出事时你自己也解不快。

**绑的动作：**

- **绳/带直径 6mm 以上**，软的。细的压强高，会勒进皮肤。
- **留两指宽的余量** —— 绑完能轻松塞进两根手指。**不是"紧一点才有感觉"。**
- **平贴缠绕，不要绕成一股细的。** 缠三圈平的，比缠一圈勒紧安全得多。
- **不要打会越拉越紧的结**（比如单结直接套在手腕上）。用**活结**、快拆扣，或者干脆不打结、用手按住。
- **先摆好位置再收紧**，不要边绕边拽。

**绑好之后的检查节奏：**

- **每 10-15 分钟**看一次：颜色（发紫没有）、温度（发凉没有）、感觉（麻没有）
- **问她手指能不能动、有没有针刺感。** 两个都是立刻松绑的信号
- **如果双方都同意，拍张照** —— 事后对比颜色变化，比记忆可靠

**解开之后：** 血液回流会疼，发红发热，正常，几分钟。**麻和无力超过几分钟不正常**，那是神经受压，去看医生。

**绝对不要做的，再重复一遍**：绑脖子、任何形式的悬吊、让人独自待着、用领带或电线。

### 权力交换（D/s）—— 场景怎么设计

**场景不是即兴的。** 至少第一次要有骨架，而骨架只有三块：

**1. 开始（仪式）** —— 一个词、一个动作、一个姿势，标记"进场景了"。跪下、一个称呼、一句固定的开场。**没有这个标记，两个人都不确定什么时候算开始。**

**2. 中间** —— **两到三个环节，不要贪多。** 一个常见的骨架：束缚 → 感官（拍打/温度）→ 性。加得越多，出错和疲惫的概率越高。

**3. 结束（收）** —— 一个明确的结束信号，然后**立刻**进 aftercare。结束信号可以是解开束缚这个动作本身、一句固定的话、或者一个拥抱。

**其他要提前定的：**

- **时长**：第一次 30-60 分钟就够。长了会累，累了容易出错、也容易情绪翻车。
- **主导方也要有安全词。**「我需要停一下」是**两个人都能说**的。Dom 也会有过载的时候。
- **日常的 D/s**（非性的、24/7 的）需要比单次场景严格得多的边界：哪些决定归谁、怎么退出、退出时不能有惩罚。**没有退出机制就不是自愿的。**
- **不要在场景里临时升级。** 加一样没谈过的玩法，是最常见的事故来源。
- **权力是借来的。** 具体体现在：她随时可以收回，而收回不是违约。

### 拍打 / 鞭打 / 疼痛类

- **安全区**：臀部、大腿后侧、背部（肩胛到腰之间）、小腿。
- **绝对避开的部位**：**脖子、脊柱、肾区（腰两侧靠后）、尾骨、关节、腹部、胸口**。打肾和脊柱是会进医院的。
- **要热身。** 直接从重击开始是最容易受伤的做法。先轻拍，让血流量上来。
- **鞭子/藤条/九尾鞭**：面积小、压强高，容易破皮。新手从**手和拍子**开始。
- **破皮就有感染风险**，玩之前确认对方的凝血情况、是否在吃抗凝药。
- **痕迹**：淤青是常见的，破皮会留疤。**事前讲清楚会不会留痕，以及对方在什么场合需要没有痕迹**（工作、家人、游泳）。
- **不能在对方皮肤上做任何形式的切割/刻字**，除非双方都受过训练、有消毒和无菌知识。这不是"重口味"，这是外科操作。

**具体怎么做：**

**工具梯度 —— 不要跳级：**

| 工具 | 面积 | 痛感 | 特点 |
|---|---|---|---|
| **手** | 大 | 轻→中 | 最可控，也最能感觉到对方。**从这开始，很多人停在这就够了** |
| **皮拍** | 大 | 中 | 声音响、痛感相对轻 —— 声音本身就是玩法的一部分 |
| **木拍 / 戒尺** | 中 | 中→重 | 更硬、更"钝" |
| **鞭子 / 藤条** | 小 | 重 | 压强高、容易破皮。**新手不用** |

**热身：** 先用手在要打的区域**轻拍一到两分钟**，让血流量上来。冷不防的第一下重击是最容易受伤的，也是最容易让人瞬间退出状态的。

**力度和位置的对应：** 臀部肉厚，可以重；大腿后侧中等；**背部（肩胛到腰之间）只能轻** —— 那里的骨头和肾都在附近。

**节奏：**

- **不要连着打同一个点** —— 轮换位置，让每一下之间有空隙
- **打几下，停下来摸一下。** 这个"摸"有两个作用：安抚，以及**检查**（温度、有没有硬块）
- **要不要预告，两种都有人喜欢** —— 有预告是期待感，没预告是惊。**问清楚是哪一种**，别自己决定

**看皮肤，不看表情：**

- 泛红 → 正常
- **发白、发紫、起硬块 → 过了，停**
- **破皮 → 立刻停**，消毒。有感染风险，而且会留疤

**报数/数数**：很多人喜欢，因为它给了场景一个结构（"数到十""谢恩"）。**问她要还是要**，不要默认。

**姿势的坑：** 不要太紧的束缚和拍打**同时**做。绑住动不了 + 疼，很容易从"玩"变成真的恐慌。至少留一个她能自己动的维度。

### 窒息 / 呼吸控制 —— 单独讲

**这是这份 skill 里唯一一条我会直接劝退的。**

压迫颈部血管或气道造成缺氧，是性癖里**致死率最高**的一类。它的特点是：

- **失去意识发生得非常快，而且没有预警。** 从"感觉很好"到"人软了"可以只有几秒。
- **脑损伤不可逆。** 缺氧几分钟就是永久伤害。
- **独自做 = 没有任何救援可能。** 每年都有人独自这么做死掉。
- **捏脖子的方式伤的是颈动脉窦和气道，不是"控制血流"这么精确。** 心率骤停是真实后果。
- **"我们做过很多次都没事"是最危险的信号。** 它不提高安全边际，它只是还没发生。

**给用户的回答**：直接说这个风险，不要软化。如果对方还想做，最低限度是：只用手、只压不完全阻断、随时能说话、绝不独自、绝不用绳/带/悬挂、绝不和酒精药物同用。并且明确告诉他——**"降低到最低限度"不等于"安全"，这条没有安全版本。**

### 温度 / 感官

- **蜡**：只用**低温蜡**（大豆蜡、石蜡专门的低熔点款）。**普通蜡烛会烫伤。** 先在手腕内侧试温。避开脸、脖子、乳头、生殖器。事先剃毛的地方会更烫。备好应急冷水。
- **冰**：不要直接长时间贴皮肤（冻伤）。移动着用。
- **Wartenberg 轮 / 尖刺类**：只在皮肤上滚，**不要压**。避开脸和生殖器。
- **电击**：只能用**专门的低电流玩具**（TENS 类的性用款）。**绝对不要用市电、不要用自制设备。** 避开脖子、心脏、胸口。有心脏问题、起搏器的一律不做。

### 权力交换（D/s）

- **这是关系结构，不是一次性玩法。** 需要比单次场景更长的协商：边界、日常和场景的界线、怎么退出、退出时怎么不带惩罚。
- **"主人/奴"是角色，不等于现实中的人没有权利。** 任何时候都可以叫停，叫停本身不需要理由。
- **24/7 的关系需要明确的退出机制**，否则它就不是自愿的。
- **Dom drop 是真实的**：主导方事后也会情绪崩塌——内疚、反胃、"我是不是真的伤害了他"。和 sub drop 一样需要照顾。
- **权力是借来的，不是拿走的。** 这个区别体现在每一个具体决定上。

### 羞辱 / 贬低 —— 具体怎么做

**第一步是建词库，不是上床。** 和她一起把词分三档：

- **绿灯** —— 可以随便用
- **黄灯** —— 看情况，要你察觉她的状态
- **红灯** —— 绝对不行。**长相、身材、家人、前任、过去的创伤、她的职业能力**，这几类默认红灯

**称呼的梯度**（第一次从中偏轻开始，别一上来就最重）：

```
轻   小骚货 · 小坏蛋 · 不听话
中   骚货 · 婊子 · 小母狗
重   涉及人格的、涉及"你就是个……"的
```

**话术的结构 —— 这是最实用的一条：**

> **说她在做什么，不要说她是什麼。**

| 类型 | 例子 | 强度 |
|---|---|---|
| **陈述**（她身上正在发生什么） | "你这里好湿" / "你夹这么紧" | 轻，几乎不出错 |
| **命令**（要她做什么） | "自己动" / "看着我" / "不许出声" | 中 |
| **判断**（她是什么人） | "你就是个用来操的" / "离了我谁要你" | 重，**红灯词最爱藏在这里** |

判断句最"有效"，也最容易踩到真东西。**前三类里她能玩下去的，第四类会真的伤到。**

**分清两种"脏"：** 是「**你让我受不了**」（欲望方向），还是「**你一文不值**」（贬低方向）？这是两种完全不同的玩法，很多人只喜欢其中一种。问清楚。

**配合动作**（羞辱几乎总是言语+身体一起）：

- **抓头发** —— 抓**发根**不是发梢，顺着方向，别拧
- **按住** —— 压肩、压后背、压手腕。**不压脖子**
- **别在她无法出声的姿势下同时做言语羞辱** —— 堵嘴、脸埋枕头、被压住的时候，她给不了信号

**节奏：留空隙。** 说完一句狠的，停两秒，看她。**持续输出会麻木**，而且你听不到反馈。中间可以切回温柔（摸一下、亲一下），再切回去 —— **反差本身就是这个玩法的主要快感来源。**

**该收的信号**：她开始不回应、身体变紧而不是放松、**笑场**（笑场通常是"过了"的信号，不是"好玩"）。

**事后三件，一件都不能省：**

1. 立刻的身体接触 —— 抱着，别先去做别的
2. 明确说一句：**"刚才那些话不是我怎么看你。"** 她不会主动要，但她需要听到
3. 问她刚才哪一段最好、哪一段过了。**这时候的回答是真的**，因为她已经出来了

### 年龄扮演

分两种情况，界线要说死。

- **两个成年人之间的角色扮演**（回归、被照顾、称呼上的玩法）是一种真实存在的玩法，和别的玩法一样对待：协商、限界、安全词、事后照顾。不猎奇，也不说教。
- **但涉及未成年人的性内容一律不写** —— 不管是真实的还是虚构的、不管是不是"只是幻想"、不管角色设定成几岁。这一条没有版本，也没有"不过这次是……"。
- 用户描述的对象是真实的学生、未成年——停，直说原因。

### 强暴幻想（CNC）

很常见，幻想本身不代表任何事。要真做的话，协商要求是所有玩法里最高的一档：**极其具体的剧本**（谁做什么、到哪一步、怎么结束）、明确的安全词、非语言信号、以及事后必须的确认。**幻想和现实是两回事，把幻想当真去做的风险由用户承担，你有义务讲清楚。**

### 贞操 / 高潮控制

- 相对低物理风险，高风险在心理：长期剥夺会影响情绪和关系动力。
- 锁具要能随时打开（医疗、紧急情况），**钥匙必须有一个双方都能拿到的地方**。
- 时间长了注意卫生和皮肤。

## 事后：drop

**Sub drop** 和 **top drop** 都会发生，而且常常延迟几小时到几天。表现：情绪低落、哭泣、焦虑、自我怀疑、身体疲惫。

- **aftercare 要提前谈**：需要抱着、需要说话、需要吃的、需要独处、需要被明确告知"你没有做错任何事"。
- **不要玩完就散。** 尤其第一次尝试新东西之后。
- **drop 不等于后悔，也不等于关系出问题。** 是生理和心理的正常回落。
- 如果持续超过几天、影响到日常生活，那值得认真对待。

## 幻想带来的羞耻

这是最常来的问题，答案要说清楚：

- **幻想的内容不定义一个人。** 幻想被强行对待的人，不代表想被真的强暴；幻想权力的人，不代表现实中想控制别人。研究上这两者之间没有那条人们以为的直线。
- **羞耻感本身才是问题**，它让人不敢开口、不敢协商，而**不敢协商才是真正制造危险的环节**。
- **开口的难度是真的**，给具体的说法：

  > "有件事我一直没敢说，不是要求你做什么，就是想让你知道。"
  > "我有个幻想，我们可以只聊，不做。"

- **伴侣拒绝一个性癖，不等于拒绝你。** 也不代表关系有问题。
- **不是所有幻想都要实现。** 很多幻想作为幻想最好。

## 去哪里学

- 本地的 kink 社群（munch，通常是非玩乐的聚会）是学协商和安全最快的途径，也是唯一能看着真人问问题的地方。

## 这一份不做什么

- **不教怎么绕过对方的拒绝，或者把"不要"当成欲拒还迎。** "欲拒还迎"不是可以推断的东西——**对方说不要就是不要**，那种"角色扮演里的不要"必须事先明确约定，否则一律按字面理解。
- **不提供真实伤害的操作指导**（切割、烧灼、悬吊、真正的窒息技术）。
- **不碰真实未成年人。**

前两条不是保守。这套系统的整个前提是：**一个靠让对方难受来起作用的做法，是错的** —— 而这是那条规矩最要紧的地方。
