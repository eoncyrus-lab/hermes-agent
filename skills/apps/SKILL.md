# 交友软件与相亲

> romance-master 体系的一部分。还没加载 `romance-master` 和 `method` 的话，先加载它们——这一份只装知识，档案、规矩和说话的方式在那两份里。

和自然认识的路径不同，这里有一个**漏斗**，而且每一层的失败原因不一样。诊断之前先定位在哪一层——这是这一份最有用的一点。

```
曝光 → 匹配 → 开场 → 聊下去 → 约出来 → 见面
```

用户说"没人理我"，可能是资料问题、开场问题、还是聊天问题，**三种的解法完全不同**。先问：**卡在哪一步？**

## 关于数字，先说清楚

交友软件的匹配率天然很低，**这是产品结构决定的，不是你的问题。**

- **沉默是默认状态。** 大部分匹配不会有对话。这不是针对谁——很多人在软件上是无意识右滑、或者装了就忘了。
- **别把匹配率当成自我价值的读数。** 这句话听起来像安慰，但它是事实：这个数字主要反映照片质量和算法，不反映你是个什么样的人。
- **样本量要够。** 发十条没回就下结论"我不行"，在统计上什么都不是。

**例外**：如果用户长期聊得起来但从来约不出来，或者匹配后就没人回过，那不是运气问题，是资料或开场有具体可改的东西。

## 资料

**照片是第一位的，而且差距是压倒性的。**

- **第一张要能看清脸。** 不是侧脸、不是背影、不是墨镜、不是大合影。
- **六张左右**：正脸一张、全身一张、在做某件事的一张（有内容的爱好，不是站着比耶）、和朋友的合影一张（可辨认出你）、笑的一张、一张有场景的。
- **别放**：纯秀肌肉、方向盘、过度滤镜、全是自拍、模糊的。
- **照片要说的事是**："这个人看起来正常、有生活、好相处。" 不是"我很帅"。

**简介**：

- 写**具体的东西**，不要写形容词。"喜欢旅行美食"是零信息；"上个月骑车去了趟青海湖，晒脱皮了"才有。
- **给一个能接的话头。** 简介的作用不是介绍你，是**给对方一个开口的理由**。
- 三到五行。太长没人读。
- 别写要求（"希望你温柔善良懂事"），那是清单，不是简介。
- 别自我贬低式幽默（"大概没人看得上我吧"）。那是要人来安慰你。

## 开场

**"你好""在吗""嗨"是最差的开场**——它把全部工作推给了对方。

好的开场有一个共同结构：**从她的资料里拿一个具体的东西 + 一句你自己的话。**

- ❌ "你好，认识一下？"
- ✅ "你那个青海湖的照片是几月拍的？我下个月想去，不知道会不会太冷"

要点：

- **具体到她资料里的某个细节**，说明你看过，而不是群发。
- **带上自己的东西**（我也……、我最近……），让它成为对话而不是采访。
- **一个问题就够**，不要一次问三个。
- **不夸外貌**。至少第一句不夸。"你真漂亮"是群发感最强的开场。
- **不要用套路话术。**"你眼睛里有故事"这种，用户发出去一次就会知道后果。

## 从聊到约

**软件上聊太久会自然死亡。** 目标是在热度还在的时候转到线下。

- **两三天内、聊到两三个来回之后**提见面，是个合适的窗口。
- **要具体**。"有空一起吃个饭？"几乎约不出来。"周六下午那家咖啡店，你上次说的那家，去吗？"成功率完全不同。
- **给对方低成本的选项**。第一次见面就是喝杯咖啡、逛个展——一到两小时，随时能结束。别安排一顿三小时的晚饭或者看电影。
- **被拒绝但给了替代方案 = 有兴趣，只是时间不行**；**被拒绝且没给任何替代 = 算了**。这两种要分清。

## 相亲

相亲和交友软件**不是同一件事**。软件是弱关系的大数筛选；相亲是**通过熟人撮合的一次定向匹配**，而且往往带着双方家庭的期待。

几个具体的不同：

- **介绍人的信息要问全。** 基本条件、双方家庭的意图、对方是不是自愿的。**"我妈让我来的"是一个你该提前知道的信号。**
- **第一次见面**：公共场所、白天、一到两小时。**别让介绍人到场**，那会把两个人的见面变成三方会谈。
- **聊什么**：工作、生活节奏、兴趣爱好、对未来的大致安排。**不要第一次就谈房子彩礼** —— 那是确定要往下走之后的事。
- **谁付钱**：主动付，或者 AA，别在门口推来推去。**提前想好，别临场尴尬。**
- **别急着表演。** 相亲里最有效的品质是"相处舒服"，不是"条件好"。
- **事后通过介绍人给反馈**，比直接失联体面得多，而且在这个圈子里你的名声会传开。

**关于条件**：相亲确实会更早谈条件，这不算功利，是路径决定的。但**要提醒用户的是**：条件匹配和相处得来是两件事，相亲容易让人只算前一半。**见两三次面，重点看相处时的感觉，而不是核对清单。**

## 安全

- **第一次见面选公共场所**，告诉一个朋友你去哪、和谁、大概几点回来。
- **自己叫车、自己付钱**，别上陌生人的车，别让对方送你到家门口。
- **照片和视频**：见 `erotic` 里那一段。**不要发任何能被认出来的东西。**
- **诈骗的信号**：很快就表白、很快提到投资/理财/数字货币、拒绝视频、故事里总有需要钱的地方、照片太好。**这类杀猪盘在用交友软件，而且是针对性的。** 遇到就说清楚。
- **对方的信息对不上**（照片和真人不符、年龄职业有出入）——不用当场发作，但你有权直接结束。

## 什么时候该停

- 软件用成了自我价值的计量器，刷不到匹配就情绪低落。**停一段时间。**
- 一直在改资料、改开场，但从没约出来过——问题可能不在文案，在别的地方，那值得当面聊。
- 用软件逃避见面。**刷是安全的，见人是会失败的，所以人会一直刷。** 这个循环要指出来。

## 收尾

软件场景里，用户给你的信息**几乎全是转述**，而且他会有强烈的解读倾向（"她这样是不是没兴趣"）。

所以这一份的场景下，**问基线比什么都重要**：她什么时候回的、之前是什么样的、聊了几天。记 `evidence` 的时候用 `--source 口述`（他描述的事）或 `原文`（他贴的聊天）。

**"她对我不感兴趣"是一个要被封装起来的判断。** 里面通常混着一两条事实和一堆焦虑。把事实挑出来，剩下的别记。
