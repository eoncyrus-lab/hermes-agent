# 手法与身体

> romance-master 体系的一部分。还没加载 `romance-master` 和 `method` 的话，先加载它们——这一份只装知识，档案、规矩和说话的方式在那两份里。

这份是**操作层**。`intimacy` 管的是沟通和契合度——两个人怎么谈、怎么发现彼此要什么；这一份管的是谈完之后具体怎么做。

写给成年人。用普通成年人的词。**不要用"私处""下体""那里"** ——用户来问姿势，回答说"可以尝试不同的体位"等于没回答。

## 先讲清楚：没有通用公式

最常被问的是"什么姿势最好"。这个问题没有答案，因为**姿势之间的差别不在姿势本身，在下面这几个变量**。想清楚变量，任何一个姿势都能自己调整：

| 变量 | 影响什么 |
|---|---|
| **角度** | 进入的方向。朝前壁、朝后壁、朝宫颈，感觉完全不同 |
| **深度** | 能控制多深。有些人不舒服就是因为太深，不是因为有病 |
| **阴蒂接触** | 大部分有外阴的人**单靠进入到不了**。姿势能不能同时给到阴蒂刺激，是最大的分水岭 |
| **主动权在谁** | 谁控制节奏和幅度。这一项对心理感受的影响经常比物理刺激更大 |
| **视线和距离** | 能不能看着对方、能不能亲到。面对面和背对面是不同的东西 |
| **体力** | 谁能撑多久。一个十分钟就累的姿势，再好也没用 |
| **身体限制** | 腰、膝、肩、体重、孕期、经期。这些是硬约束，不是"克服一下" |

所以正确的问法不是"哪个姿势好"，是"**你们缺的是哪一项**"：到不了 → 大概率缺阴蒂接触；疼 → 大概率是深度或角度；一方走神 → 大概率是主动权或视线。

## 前戏

**先纠正这个词。**「前」戏这个说法把这件事定义成"正戏之前"，暗示插入才是正事。**对大多数有外阴的人来说，前面这些就是性本身** —— 单靠插入到不了的人是多数。所以别把它当热身，把它当正餐。

**它需要时间，而且是生理性的。** 阴道扩张和分泌通常要十几分钟（因人差异极大）。这不是"她不够放松"，是生理过程，催不得。跳过它直接进，结果就是疼。

**而且对很多人，唤起是"反应性"的** —— 不是先想要才开始，是先有身体刺激，然后才想要。所以「等她想要了再开始」是个死循环。（完整解释在 `intimacy` 的 Desire 那节。）

**它不是一套流程。** 最常见的错误是当成清单走：亲嘴 → 摸胸 → 往下。那会变得机械，而且对方**能感觉到你在走流程**。

**具体做：**

- **先处理环境。** 不需要蜡烛，但**「不被打断」是硬要求**：手机静音、门锁上、孩子和室友安排好、时间上不赶。这几样比任何技巧都重要，也是最常被忽略的。
- **从和性无关的接触开始。** 一上来就直取要害，等于跳过了「从日常切到当下」那一段。肩膀、后颈、后背、头发、手、膝盖内侧 —— 这些地方的作用不是热身，是让注意力落回身体。
- **慢。真的慢。** 多数人的节奏偏快。**手在同一个地方多停一会儿，比多换几个地方有用。**
- **隔着衣服那一段被严重低估。** 直接皮肤接触之前的张力最强，很多人急着跳过去。
- **嘴和呼吸。** 耳朵、脖子、锁骨、大腿内侧。对着皮肤慢慢呼气，比很多动作有用。
- **看反馈，不看时间。** 呼吸变没变、有没有声音、身体是前倾还是僵住、有没有主动要更多。**安静和僵住是停的信号，不是"继续"。**
- **它是双向的。** 「她给我口交然后直接进去」不是前戏，是跳步。她也应该被摸、被要、被回应。

**时长**：二十到四十分钟对多数人舒服，**但别看表** —— 看反应。太久会累、会干、张力会散掉。

**她如果催你"直接来"**：有时候是真想要，有时候是不想让你费事。问一句。**而且即使她想直接来，润滑还是要上。**

**被打断之后**（孩子哭了、电话响了）：回来要**重新开始**，不能接着刚才那一步往下走。而且不要表现出烦躁 —— 那个表情会被记住很久。

**常见错误，按发生频率排：**

1. 太快
2. 当成任务清单，一项项打勾
3. 一边摸一边想别的事（对方察觉得到）
4. 单向：只对她做，不接受她做的
5. **把「她湿了」当成「她准备好了」** —— 唤起和润滑不完全同步，而且润滑不等于想要

## 手

最被低估、也最可靠的一样。对自己的身体最熟的人，用手的效率通常高于任何其它方式。

- **润滑不是可选项。** 干手是很多人觉得"手不如别的"的唯一原因。
- **间接往往比直接好。** 隔着包皮、阴蒂 hood、内裤，或者用整个手掌而不是指尖。直接刺激阴蒂头对不少人来说是**过度**刺激，不是愉悦。
- **画圈、上下、压、揉，频率和力度分开调。** 一次只改一个变量，才知道是哪个起了作用。
- **不要只盯着一个点。** 大腿内侧、小腹、腰、脖子、耳后——这些地方的作用是让整件事不是一个局部操作。
- **手指进入时，找前壁而不是往里捅。** 弯起手指、掌心朝上、"come hither"那个动作，覆盖的范围比直进直出大得多。
- **剪指甲，洗手。** 不是客套话，是字面意义上的。

## 口

- **mouth 的湿度会变。** 唾液会干，干了就变成摩擦。中间补润滑或者用嘴+手配合。
- **下巴和脖子会累。** 提前换个能撑住的姿势（对方在床边、你在跪姿垫上），比中途停下来好。
- **牙齿收起来**，除非对方明确说喜欢。
- **节奏恒定比花样多更容易到。** 很多人接近高潮时需要的是"别变"，不是"再来点新的"。这一点男方尤其容易搞错——**她说"别停"就是字面意思的别停，不是"换个更厉害的"。**
- **69 的物理问题**：两个人都想专注，但两个人都在分心。它作为前戏很好，作为"到"的手段对多数人效率低。

## 进入

- **润滑先上，进去再说。** 前戏充分不代表不需要润滑，尤其是围绝经期之后、服药期间、或者刚洗完澡。
- **角度比力度重要。** 一开始慢、浅、找方向，比直接到底好。
- **宫颈被顶到是疼的**，不是"酸爽"。如果对方说疼，改角度或改深度，不要"再适应一下"。
- **想给阴蒂刺激就用手**，同时进行。绝大多数有外阴的人需要这个，而且这不是"前戏没做好"的补偿。
- **后入**容易更深、也容易控制角度，但看不到脸、也常够不到阴蒂——所以它常常"感觉强烈但不一定能到"。
- **女上位**把主动权交给对方，节奏和深度都更容易自己调，而且通常能同时给到阴蒂。累了可以换成靠着你的坐姿。
- **侧躺**省体力、能面对面、能空出一只手，适合时间长的和身体不方便的。
- **垫高臀部**（枕头）改变角度，是低成本高收益的调整，很多人没试过。

## 节奏、时间和"到不了"

- **接近高潮时改变刺激是最常见的错误。** 稳定、可预测、持续——这三样比"更强烈"重要得多。
- **时间长短不是成绩。** 插入时间过长，对双方都是摩擦和疲劳。前戏和插入后的事往往更重要。
- **早泄**：多数情况是焦虑驱动的，越怕越快。可行的手段有：停-动法、挤捏法、加厚避孕套、局部麻醉喷剂（会同时降低对方感觉，用套）、以及把重点从插入移开。持续存在就值得看医生，这不是"意志力问题"。
- **延迟射精/到不了**：先排查药物（SSRI 类很常见）、酒精、疲劳。然后看是不是"表演焦虑"——越想着要让她到，越到不了。
- **到不了不是对方的失败，也不是你的失败。** 有相当比例的人（尤其女性）在性交中从不或很少高潮，而这不代表她们不喜欢这件事。把高潮当成必须完成的任务，是让它更不可能发生的最快方法。

### 「到不了」的具体手段

如果用户问的是**怎么办**（而不只是为什么），按这个顺序给。**一次试一样**，同时改几样就不知道是哪样起了作用。

1. **加阴蒂刺激，同时进行。** 这是命中率最高的一条。手、子弹振动器、气压式玩具，做的时候同时用。**不是"前戏没做够"的补偿，是常规操作。**
2. **换刺激的**种类**，不是换强度。** 一直用手就到不了 → 换振动；振动麻木了 → 换气压式（不靠振动，靠压力波）；都不行 → 换口或换角度。**很多人只是没找到对的那一种。**
3. **让它变成"可以发生"而不是"必须发生"。** 把「到」从目标里拿掉——**"今天不一定要到"这句话本身，经常就是它可以发生的原因。** 表演焦虑是最常见的抑制因素，而它来自"必须到"。
4. **看她是不是在演。** 有些人的"到不了"是因为觉得必须到给你看，于是分心在表演上。**直接问："你是真的想要，还是在配合我？"** 这句话本身就能松掉很多东西。
5. **排查药物。** SSRI 类抗抑郁药、部分降压药、抗组胺药都会延迟或阻止高潮。**这是可讨论的** —— 找开药的医生，不要自己停药。
6. **检查她是不是在忍别的事。** 疼、想上厕所、姿势不舒服、担心孩子醒、担心身材。这些都会直接压掉高潮，而当事人往往不说。
7. **器械辅助不是失败。** 用振动器才能到的人占相当大的比例。**把它当工具，不当拐杖。**

**如果反复试还是不行，而且她本人为此困扰**：那是值得看医生或性治疗师的事，不是继续加把劲的事。

## 玩具

玩具是**工具**，不是替代品，也不是"不够好才用"。先说最容易踩的坑：

**润滑剂和材质的相容性 —— 这个搞错会毁东西：**

| 润滑 | 能用在哪 | 不能碰 |
|---|---|---|
| 水基 | 所有玩具、所有避孕套 | 容易干，要中途补 |
| 硅基 | 乳胶避孕套、玻璃、金属、硬塑料 | **硅胶玩具**（会溶胀、发黏、报废） |
| 油基 | 硅胶玩具、玻璃、金属 | **乳胶避孕套**（会破）、易引起不适 |

**材质决定了能不能彻底清洁：**

- **铂金硅胶 / 医用硅胶**：无孔，可煮沸、可洗碗机、可用 10% 漂白水。首选。
- **TPE / TPR / "真实触感"**：**有孔，藏菌，无法彻底消毒**。只能用套，且要定期换。很多便宜玩具是这种。
- **玻璃 / 不锈钢**：无孔，可煮沸，可用任何润滑。可以加温或冰镇（注意别烫伤）。
- **ABS 硬塑料**：外壳常用，无孔。

**类别和各自真正擅长什么：**

- **子弹 / 小号振动器**：精准、局部。适合阴蒂的直接刺激，但很多人会觉得太集中。
- **wand（大棒）**：范围大、强度高。对"隔着也能到"的人很有效，也让"手麻了"这件事不再发生。缺点是体积和噪音。
- **气压式（air-pulse）**：不靠振动，靠空气压力波刺激阴蒂。对"振动会麻"的人是另一条路，也是很多人第一次高潮的工具。
- **假阳具**：注意**长度和直径都量力**，以及**必须看底座**（见下面肛交那条）。
- **肛塞**：**必须是有外扩底座的**，绝不能是那种"滑进去就出不来"的形状。这是硬安全要求。
- **震动环 / cock ring**：能帮助维持硬度。**不要戴超过 20-30 分钟**，会缺血。
- **穿戴式 / 情侣玩具**：能同时给到双方，但贴合度差异极大，买之前看尺寸。
- **远程玩具**：异地关系用，注意连接稳定性——中断在最要命的时候很扫兴。

**清洁和存放**：每次用完洗，无孔的可煮沸，有孔的用玩具清洁剂+套。**不同材质分开放**（硅胶贴硅胶会融）。电池取出。

## 肛交

单独讲，因为它的风险和其它做法不是一个量级。

- **润滑要远多于你的直觉。** 直肠不分泌，且会吸收水分。硅基或厚水基，中途补。
- **慢，而且要对方主导进入的节奏。** 括约肌需要时间放松，催不得。
- **绝对只用带外扩底座的玩具。** 没有例外。急诊室取异物是真实存在的事。
- **直肠黏膜很脆弱**，容易产生看不见的微小破损 → **必须用避孕套**，且每次换人换套。这不是洁癖，是感控。
- **肛交后不要再进入阴道**，除非换套或彻底清洗。这是常见的感染来源。
- **不要用麻醉类润滑剂**（"延时""放松"那种）。疼是信号，把信号关掉不是解决。
- **灌洗不是必须的**，频繁灌洗反而破坏黏膜。正常清洁足够。

## 疼、进不去、和什么时候该看医生

**先说这条，因为它最容易被耽误：持续或反复的性交疼痛（dyspareunia）是医学问题，不是技巧问题。** 把它当技巧问题练，是很多人在这上面耗掉几年的原因。

需要看医生的信号：

- 插入时持续锐痛，或第一次就进不去（可能是阴道痉挛 vaginismus）
- 深度撞击痛（可能是子宫内膜异位、盆腔问题）
- 性交后出血
- 突发的欲望或功能变化（之前正常，最近变了）
- 勃起困难持续存在
- 任何感染迹象、避孕失败

**技巧能帮的**：润滑、放松、足够的唤起时间（唤起本身会扩张和润滑，跳过前戏直接进就是疼）、从浅到深、让对方自己控制进入。**技巧帮不了的**：上面那些 —— 直接说"这个值得看医生"，不要假装再试一次就好。

## 事后

接下来二十分钟对方需要什么，差异极大：抱着、说话、吃的、安静、空间、确认。**这不是小事** —— 对不少人来说，它对整件事的感受的影响大于前面所有环节。而且这是整个领域里最容易直接问出口的一件事：

> "你现在想让我抱着你，还是想自己躺一会儿？"

## 别忘了

这一份给的是**做法**。什么时候用、对方想不想、这次要不要——那些是 `intimacy` 的事。做得再好，做在对方不想要的时候，就是错的。

**对方的反应是证据。** 她身体前倾、呼吸变快、主动要更多 —— 这是证据。她安静了、僵住了、"嗯"了一声 —— 这也是证据，而且优先级更高。用户转述"她好像还挺喜欢"的时候，去问细节，不要替他下结论。
